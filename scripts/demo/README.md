# Rebuild the example workflow

Development-only scripts regenerate the public `docs/media/preview.png`, `demo.mp4`, and `demo.vtt` assets. They are not published with the package. Keep `docs/media/demo-transcript.md` in sync when changing choreography/captions.

## Run

Requires macOS system Menlo/Georgia/Arial fonts, Node.js and installed project dependencies, `pi`, `rg`, `fd`, Python 3, and `/opt/homebrew/bin/ffmpeg` (`ffprobe` for validation). Install Python dependencies into a disposable directory, not the project or system Python:

```sh
TOOLS="$(mktemp -d /tmp/pi-secure-media-tools.XXXXXX)"
python3 -m pip install --target "$TOOLS" pyte Pillow
export PYTHONPATH="$TOOLS${PYTHONPATH:+:$PYTHONPATH}"
python3 scripts/demo/capture.py
# Use the temporary directory printed by capture.py:
python3 scripts/demo/render.py /path/printed/by/capture/frames.json
/opt/homebrew/bin/ffprobe -v error \
  -show_entries stream=codec_name,width,height,pix_fmt \
  -show_entries format=duration,size -of json docs/media/demo.mp4
```

Dependency installation may require network access; the capture and render themselves require only localhost. Inspect `verification.json` in the capture directory, the generated preview, and video frames before accepting a recording. Capture fails if either implementation or terminal-cell assertions fail. Raw ANSI/frame snapshots and verification remain temporary, outside the repository.

## What actually runs

The capture starts an offline Pi process on a real 112×25 PTY, in a temporary working directory with isolated HOME and agent settings, an explicit environment allowlist, and no saved session, built-in tools, automatic extensions, MCP, skills, templates, or context files. Only this driver and theme are explicitly loaded. No model is called; a synthetic CLI API-key override suppresses startup warnings and is never sent to a provider. This is process/configuration isolation, not an OS network sandbox.

The driver imports the real root extension and intercepts its registered tool/command definitions. A local `/demo` command directly invokes their actual implementations with Pi's UI context. Inputs are scripted, not generated by an agent. A custom narration renderer emits editorial request/result labels, not model reasoning or model-issued tool-call records. Its custom-UI wrapper schedules keys and observes render output; it preserves the real centered overlay options and does not substitute dialog rendering.

1. Actual `request_secret` opens the prominent masked request overlay for `BUILD_TOKEN`. Four timed input chunks enter `example-local-api-token`; the real input shows 8, 14, 18, then 23 asterisks. Enter submits. The returned result contains only name/availability.
2. An ephemeral HTTP fixture binds only to `127.0.0.1`. `/builds/latest` first rejects unauthenticated access with HTTP 401. Actual `secure_exec` injects `BUILD_TOKEN` and runs `curl` with a Bearer header. The fixture checks the header and returns build 184, main, passed, 12 / 12 checks. The driver asserts exact output, exit 0, and one authenticated request. This is local fixture data, not an external build service.
3. The actual `/secret show BUILD_TOKEN` command opens its real masked local overlay. R requests reveal, Y confirms, R hides again, Enter closes. The synthetic value is briefly visible locally.
4. Actual `capture_secret` seeds fourteen additional synthetic names with `printf '%s' synthetic-browser-fixture`. These short setup calls are not narrated as model activity. `/secret list` opens the actual names-only browser with fifteen entries. Scripted j keys scroll past its twelve-row viewport to `DEMO_TOKEN_14`; Enter opens its masked dialog. Enter returns to the browser, D requests forgetting, Y confirms, and the refreshed browser selects `DEMO_TOKEN_13` with fourteen entries. Esc closes.
5. A real `secure_exec` verifies the forgotten name is unavailable. The actual `/secret clear` handler clears the remaining vault; another execution verifies `BUILD_TOKEN` is unavailable. The server closes in `finally`, then Pi shuts down.

**C remains visible but is never pressed; no clipboard callback is simulated or invoked, and no native clipboard read/write occurs.**

## Verification and edit

`verification.json` records the HTTP assertions, no scripted clipboard actions, and final clear. Component-render assertions check all four exact mask lengths, no plaintext in request/browser, masked command-show, confirmation before reveal, scrolling to 15/15, selected-name show, clear confirmation, and removal/refresh to 14/14. Separate assertions inspect the captured terminal cells for the actual request border, mask lengths, local show, scrolled selection, selected dialog, confirmation, and refreshed browser.

The renderer paints captured ANSI terminal cells with pyte/Pillow inside editorial window chrome. Title and captions are editorial; the dialogs themselves are real captures. It resamples at 10 fps and holds the final state to a 32-second timeline, then encodes silent 1280×800 H.264/yuv420p at 30 fps with faststart. The same-size PNG uses a captured masked `/secret show BUILD_TOKEN` state. VTT mirrors the burned-in captions. Captions have fixed timing; recheck them after choreography or performance changes.

## Boundary

Only use the synthetic fixtures above: raw capture deliberately retains the locally revealed value. No external service, real credential, provider request, or native clipboard operation is needed. This is transcript hygiene, not a sandbox or protection against a malicious/prompt-injected model. Commands retain ordinary OS permissions and can exfiltrate or transform secrets; exact-value output redaction does not cover every encoding. Clearing the vault does not erase recordings or files.
